# Credits

Capabilities is built on other people's work: datasets, published research, open-source software and design research. This page credits all of it. Every fact in the graph also says where it came from, in the app's detail pane.

The project itself is free for non-commercial use: the code under the [PolyForm Noncommercial License 1.0.0](LICENSE) and the data under [CC BY-NC-SA 4.0](data/LICENSE) ([ADR 0037](docs/adr/0037-license-the-project-for-non-commercial-use-only.md)). The works below keep their own licenses.

## Datasets

The upstream datasets the graph is built from ([ADR 0034](docs/adr/0034-build-the-graph-from-upstream-datasets-and-a-curated-layer.md)). USGS MRDS (since 2026-11-22), Wikidata, Pleiades, OpenAlex and Crossref (since 2026-11-24) are ingested; the others are not yet, and each row says what it will be used for. Licenses were checked on 2026-11-20. Before a new dataset is ingested, it gets a row here. A cold backup of each ingested dataset is kept in [`snapshots/`](snapshots/README.md) under the dataset's own license ([ADR 0044](docs/adr/0044-require-every-upstream-dataset-with-cold-backups-in-git.md)).

## Works cited in the data

The references behind routes, materials and numbers. Report anything wrong through the issue tracker.

## Map tiles

The map's background ([ADR 0042](docs/adr/0042-show-where-things-are-found-on-a-maplibre-map.md)) is drawn from vector tiles served by [OpenFreeMap](https://openfreemap.org/) (free public instance; its code is MIT), using the [OpenMapTiles](https://openmaptiles.org/) schema. The map data is © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), available under the Open Database License (ODbL). The map shows this attribution in its corner. Tiles are fetched by the viewer's browser and never stored in the project.
